# Security

Write to security@elchi.dev with what you found, how to reproduce it
and, if you have one, what you would change. You get an answer within
two working days and a fix as fast as the finding needs, with credit if
you want it. Please do not open a public issue for it.

This applies to every repository in the organisation and to the
services at elchi.dev, emxmail.ch and their subdomains.
