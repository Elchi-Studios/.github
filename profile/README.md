Elchi Studios makes business software the way it should have been made
all along: one sign-in for everything, data in Switzerland, prices that
stay low because nothing is outsourced, and documentation that answers
the question you came with.

## Products

| | What | Where |
| --- | --- | --- |
| **EAuth** | Sign-in for every Elchi Studios product and for yours. OpenID Connect, passkeys, organisations, hosted pages. Free, permanently. | [docs.elchi.dev/quickstart](https://docs.elchi.dev/quickstart) |
| **EMX** | Business mail. Your domain, IMAP for the apps you have, a web client, an API that does everything the client does, sealed mailboxes when you want them. | in build |
| **Console** | One place for applications, keys, team and usage across products. | [panel.elchi.dev](https://panel.elchi.dev) |

## Open source

What talks to our services is published here as it settles; the
services themselves stay closed and their API references are public.
First in line: the EMX SDK for Rust, the `emx` command line and the
desktop app.

## How we build

- Go on the server, few dependencies, everything measured.
- Documentation first, at [docs.elchi.dev](https://docs.elchi.dev):
  every endpoint, every error, with examples that carry real values.
- Security matters go to security@elchi.dev; you get an answer within
  two working days.
