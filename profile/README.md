Elchi Studios makes business software the way it should have been made
all along: one sign-in for everything, data in Switzerland, prices that
stay low because nothing is outsourced, and documentation that answers
the question you came with.

## Products

| | What | Where |
| --- | --- | --- |
| **EAuth** | Sign-in for every Elchi product and for yours. OpenID Connect, passkeys, organisations, hosted pages. Self-hosting for companies that must keep it in the building. | [docs.elchi.dev/eauth](https://docs.elchi.dev/eauth) |
| **EMX** | Business mail. Your domain, IMAP for the apps you have, a web client, an API that does everything the client does, sealed mailboxes when you want them. | [emxmail.ch](https://emxmail.ch) · [docs](https://docs.elchi.dev/emx) |
| **Console** | One place for applications, keys, team, usage and support across products. | [panel.elchi.dev](https://panel.elchi.dev) |

## Open source here

- [emx-client](https://github.com/Elchi-Studios/emx-client): the EMX SDK
  for Rust, the `emx` command line, and the desktop app. Build your own
  client against the same API we use.

More follows as products settle. The services themselves stay closed;
what talks to them is open, and the API references are public.

## How we build

- Go on the server, few dependencies, everything measured.
- Documentation first, at [docs.elchi.dev](https://docs.elchi.dev), with
  every page also as plain Markdown, to read offline or paste anywhere.
- Security matters go to security@elchi.dev; you get an answer within
  two working days.
